# 2025 archive

These pages describe the first design of Riddlen: single-answer riddles with speed tiers,
community question validators, group play, and an oracle network. The contracts were deployed
to the Polygon Amoy testnet, but the game was never played, and the design was replaced in
September 2026 by Stump the Machine. Numbers on these pages do not match the live contracts.

They are kept because the RDLN and RON tokens described here are the same contracts the game
uses today, and because the history is worth having.
